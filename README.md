## 🌟 Introduction

**Phasal Sahaayak** (Crop Helper) is a comprehensive digital agriculture platform designed specifically for Indian farmers. It provides real-time access to:

- 🌤️ **Weather forecasts** for informed farming decisions
- 🌾 **Live mandi prices** to maximize crop profits
- 🩺 **AI-powered crop disease diagnosis** through photo upload
- 📜 **Government scheme information** with direct application links
- 🧑‍🔬 **Expert consultation** and community support

The platform features a **government-style dashboard** with a professional, trustworthy appearance while remaining accessible to farmers with limited technical experience.

## 🚀 Installation & Setup

### Prerequisites

- Any modern web browser (Chrome, Firefox, Edge, Safari)
- Git (optional, for cloning)

### Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rg100152/Phasal-Sahaayak.git
   cd Phasal-Sahaayak
   ```

2. **Open the file:**
   - Double-click `index.html` to open in your browser
   - Or use a local server (VS Code Live Server recommended)

3. **That's it!** The page loads instantly with all styles, scripts, and images embedded.

### Alternative: Download ZIP

1. Visit [GitHub Repository](https://github.com/Rg100152/Phasal-Sahaayak)
2. Click "Code" → "Download ZIP"
3. Extract and open `index.html`

## 🎮 Usage Guide

### 🌐 Language Selection

- Click **"हिंदी"** or **"English"** in the header to switch languages
- All content, buttons, and notices update instantly

### 🔐 Key Features

#### 1. Weather Forecast
- Click the **🌤️ मौसम** card
- Enter your district to view 7-day forecast
- Receive emergency weather alerts

#### 2. Mandi Price Check
- Navigate to the **🌾 मंडी भाव** section
- View real-time prices for major crops
- Click **PDF डाउनलोड** to save report
- Click **प्रिंट करें** for physical copy

#### 3. AI Crop Doctor
- Click the **🩺 फसल डॉक्टर** card
- Upload a photo of the diseased leaf
- Receive AI diagnosis with treatment suggestions
- Drag & drop supported for easy upload

#### 4. Government Schemes
- Scroll to **📜 सरकारी योजनाएं** section
- View 4 major government schemes
- Click **आवेदन करें** to visit official portal

#### 5. Expert Consultation
- Click **🧑‍🔬 विशेषज्ञ सलाह** card
- Connect via WhatsApp for expert advice

### ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `1` | Weather Forecast |
| `2` | Mandi Prices |
| `3` | Crop Doctor |
| `4` | Government Schemes |

## 🔧 Configuration

This project is **self-contained** and requires no external configuration. All settings are customizable:

| Element | Location | Customization Options |
|---------|----------|-----------------------|
| **Hero Text** | `hero-content` div | Change heading and description |
| **Mandi Prices** | `#mandiTable` | Update crop names and prices |
| **Government Schemes** | `.schemes-grid` | Add/remove schemes |
| **Notices** | `notices` array | Add custom alerts |
| **Images** | All `src` attributes | Replace with your own images |
| **Colors** | CSS `:root` variables | Update theme colors |
| **Language** | `changeLanguage()` | Add more languages |
